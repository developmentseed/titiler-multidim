# Custom colormaps

Every `.npy` file in this directory is registered at startup under its file name and
can be requested with `colormap_name=<name>`. Each is a 256-row RGBA lookup table that
titiler applies **after** `rescale` stretches the data to 0-255, so each one is only
meaningful with the `rescale` listed below.

The files are generated by `scripts/make_cmaps.py`; `tests/test_cmaps.py` fails if a
committed file no longer matches the script. Do not edit the `.npy` files by hand.

| `colormap_name` | Source | Use with |
|---|---|---|
| `worldview_rainbow_4` | NASA Worldview custom palette "Rainbow 4", copied verbatim (255 colors) from [nasa-gibs/worldview](https://github.com/nasa-gibs/worldview/blob/main/config/default/common/config/palettes-custom.json/rainbow_4.json), kept in `scripts/cmap_sources/` | the value range you would set in Worldview, e.g. `rescale=0,2e16` for TEMPO NO2 tropospheric column in molecules/cm² |
| `naqfc_o3` | NOAA Air Quality Forecast Guidance Viewer ozone ramp, one color per 10 ppb, sampled from the viewer for [veda-backend#665](https://github.com/NASA-IMPACT/veda-backend/pull/665) | `rescale=0,200` for data in ppb, `rescale=0,0.2` for ppm |
| `naqfc_pm25` | the ozone ramp above, stretched so each EPA 24-hour PM2.5 AQI category (bounds 9.0, 35.4, 55.4, 125.4, 225.4 µg/m³) spans the same colors as its 8-hour ozone category (54, 70, 85, 105, 200 ppb) | `rescale=0,225.4` for data in µg/m³ |

Known limits:

- The NAQFC ramps are sampled from a screenshot, not from a provider color table. The
  provider's stated intent (Air-Quality-Portal/aq-arch#192) is category boundaries at
  the EPA breakpoints with a gradient inside each category; the ozone ramp as sampled
  does not change color exactly at those breakpoints. Replace the stops in
  `scripts/make_cmaps.py` when the provider supplies the table.
- A lookup table places category boundaries to the nearest 1/255 of the `rescale`
  range: 0.8 ppb for ozone, 0.9 µg/m³ for PM2.5.
- Values above the `rescale` maximum take the top color; values below the minimum take
  the bottom color.
